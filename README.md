# Virtual Business Card

This project is a responsive and interactive virtual business card created using HTML, CSS, and JavaScript.  
It is designed to showcase personal and professional information in a clean and visually appealing way.

## 🔹 Features
- Responsive card layout
- Animated typing bio
- Light and Dark mode toggle
- Clickable social media links
- Downloadable vCard (.vcf)
- QR code for easy sharing

## 🔹 Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts
